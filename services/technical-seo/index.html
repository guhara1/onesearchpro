기술 SEO 점검 항목

검색엔진이 사이트를 제대로 읽고 이해할 수 있도록 8개 영역을 점검합니다.

🔍

색인·크롤링 점검

구글·네이버 색인 여부, 크롤링 차단, noindex 오설정, 페이지 발견성 문제를 진단합니다.

  • 서치콘솔 커버리지 분석
  • 크롤링 예산 점검
📄

robots.txt · sitemap

robots.txt 규칙 검증과 XML 사이트맵 구조·우선순위·갱신 주기 최적화.

  • 다중 sitemap 분리
  • 이미지·뉴스 sitemap
🔗

canonical · 중복 URL

파라미터·페이지네이션·hreflang으로 인한 중복 콘텐츠와 canonical 누락 해결.

  • URL 정규화
  • 중복 페이지 통합
⚡

Core Web Vitals

LCP, INP, CLS 점수를 실측하고 이미지·CSS·JS·서버 응답을 개선합니다.

  • 이미지 LCP 최적화
  • JS 번들 분할
📱

모바일 사용성

모바일 우선 색인 기준으로 뷰포트, 탭 영역, 가독성을 점검합니다.

  • 모바일 친화성 테스트
  • 터치 타겟 크기
🏷️

구조화 데이터

Organization, FAQ, Article, Product 등 검색 결과에 풍부한 결과를 만들어내는 스키마 마크업.

  • JSON-LD 적용
  • Rich Results 테스트
🌐

HTTPS · 보안

SSL, 혼합 콘텐츠, HSTS, 보안 헤더가 검색 신뢰도에 영향을 줍니다.

  • 혼합 콘텐츠 해결
  • 보안 헤더 설정
🧭

내부 링크 구조

앵커텍스트, 깊이, 고립 페이지(orphan)를 점검해 크롤링 효율을 높입니다.

  • 내부 링크 흐름 분석
  • 고립 페이지 연결
