신규 도메인 — 색인 자체가 안 되던 사이트

작업 전 문제

런칭 후 몇 달이 지나도 구글 색인에 거의 잡히지 않았습니다.

진단 결과

robots.txt에서 일부 디렉토리가 차단되어 있었고, canonical과 메타 robots noindex가 잘못 설정된 페이지가 다수였습니다.

개선한 항목

  • robots.txt 재작성과 차단 규칙 해제
  • canonical·noindex 설정 점검과 수정
  • sitemap 재생성과 서치콘솔 색인 요청

적용 후 변화

  • 주요 페이지 대부분 색인 정상화
  • 키워드 노출 시작
  • 작업 기간 약 4주

주의할 점

색인 정상화 자체와 상위 노출은 별개입니다. 색인 이후에도 콘텐츠·외부 신호 작업이 필요합니다.

DUPLICATE
🧩

대형 쇼핑몰 — 중복 URL 문제 정리

작업 전 문제

제품 페이지가 옵션·필터·정렬에 따라 수만 개의 중복 URL로 색인되어 크롤링 예산이 낭비되고 있었습니다.

진단 결과

canonical 미설정·중복 메타·중복 콘텐츠가 누적되어 핵심 페이지가 평가받지 못하는 상태였습니다.

개선한 항목

  • 옵션·필터 파라미터에 대한 canonical 설정
  • 파라미터별 noindex·meta robots 규칙 정비
  • sitemap에서 핵심 페이지만 포함

적용 후 변화

  • 크롤링 통계상 핵심 페이지 방문 증가
  • 중복 색인 페이지 점진적 감소
  • 작업 기간 약 3개월

주의할 점

대규모 색인 정리는 단기 트래픽 변동이 발생할 수 있으며, 분기 단위 추적이 필요합니다.

⚠️

중소 비즈니스 — 수동 조치(Manual Action) 회복

작업 전 문제

과거 대량 백링크 작업의 영향으로 서치콘솔에서 수동 조치 메시지를 받은 상태였습니다.

진단 결과

위험한 외부 백링크가 다수 식별되었고, 일부 자체 콘텐츠에서도 가이드라인 위반 패턴이 확인되었습니다.

개선한 항목

  • 위험 백링크 식별과 Disavow 파일 제출
  • 내부 가이드라인 위반 콘텐츠 정비
  • 서치콘솔 재심사 요청과 결과 모니터링

적용 후 변화

  • 수동 조치 해제
  • 기본 검색 노출 복귀
  • 회복 기간 약 3~4개월

주의할 점

수동 조치 회복은 자동으로 보장되지 않습니다. 재심사 통과까지 여러 번 시도가 필요할 수 있으며, 회복 후에도 신뢰 회복은 별개입니다.
