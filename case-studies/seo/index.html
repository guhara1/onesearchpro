B2B SaaS — 핵심 키워드 진입 회복

작업 전 문제

자체 블로그가 있지만 핵심 상업 키워드 검색에서 거의 노출되지 않았고, 경쟁사 대비 도메인 권위가 낮은 상태였습니다.

진단 결과

키워드 매핑이 검색 의도와 어긋나 있었고, 페이지 간 토픽이 분산되어 토픽 권위가 형성되지 않았습니다. 내부 링크도 사실상 없었습니다.

개선한 항목

  • 필러 페이지 1개 + 클러스터 8개로 토픽 구조 재설계
  • 타이틀·H1·메타 재작성과 검색 의도 매칭
  • 내부 링크 흐름 재구성과 앵커텍스트 통일

적용 후 변화

  • 타겟 키워드 중 다수가 1~2페이지로 이동
  • 오가닉 세션 약 2~3배 수준으로 증가
  • 전체 작업 기간 약 6개월

주의할 점

신규 페이지의 색인까지 시간이 걸리며, 동일한 결과가 모든 산업에서 보장되지는 않습니다. 검색 트렌드 변화 시 재조정이 필요합니다.

EDU
🎓

온라인 교육 — 카테고리 페이지 재구성

작업 전 문제

강의 카테고리 페이지가 빈약해서 카테고리 단위 키워드에서 경쟁사보다 뒤로 밀려 있었습니다.

진단 결과

카테고리 페이지에 본문이 거의 없고 H1·H2 구조가 정렬되지 않은 상태였습니다. 또한 비교형 검색 의도("○○ 강의 비교")에 맞는 콘텐츠가 없었습니다.

개선한 항목

  • 카테고리 페이지에 비교·선택 가이드 본문 추가
  • 스키마 마크업(BreadcrumbList, ItemList) 적용
  • 내부 링크에서 카테고리로 권위 집중

적용 후 변화

  • 카테고리 키워드 평균 노출 순위 개선
  • 카테고리 페이지 직접 방문 증가
  • 작업 기간 약 4개월

주의할 점

구글의 카테고리·리스트 페이지 평가는 자주 바뀌므로 분기 단위 점검이 필요합니다.

산업 전문 미디어 — 기존 도메인 권위 활용

작업 전 문제

기존 도메인 권위는 있지만, 신규 비즈니스 영역 키워드에서 거의 노출되지 않았습니다.

진단 결과

기존 콘텐츠와 신규 비즈니스 키워드 사이에 토픽 연결 고리가 없어 신규 페이지가 평가받지 못했습니다.

개선한 항목

  • 기존 인기 콘텐츠에서 신규 페이지로 내부 링크
  • 신규 영역 토픽 클러스터 신규 구축
  • 메타·OG·스키마 일관성 정비

적용 후 변화

  • 신규 영역 핵심 키워드 색인·노출 시작
  • 기존 트래픽 손실 없음
  • 작업 기간 약 5개월

주의할 점

기존 인기 콘텐츠의 트래픽이 새 페이지로 이동하는 효과는 신중하게 관찰해야 합니다.
